# Archived web replay workbench

This directory preserves the previous browser-oriented prototype as a
reference while the product moves to the native Slint frontend.

```text
frontend/   old Next.js / React workbench
backend/    old Rust HTTP API used by that workbench
```

It is not the active Quant Replay Studio path. New product work belongs in
`frontend/` (Slint) and `systems/quant_replay_engine/` (Runner).
Keep this archive available for research UI ideas and migration comparison;
do not add new product features here.
