## Method

The script pairs `BONK1MUSDC` and `BONK1MUSDT` at each minute and rebuilds the core cross-venue variables:

```text
basis_usdc_minus_usdt_bps
spread_usdc_minus_usdt_bps
log_activity_usdc_over_usdt / usdc_activity_share
microprice_usdc_minus_usdt_bps
microprice_basis_usdc_minus_usdt_bps
```

Lead/lag is tested with exact minute offsets: current USDC one-minute return versus later USDT one-minute return, and the reverse. Convergence is tested with exact future basis at 5m/15m/30m/1h/4h/12h. Incremental value is tested by fitting depth+BONK-RV controls on train-side history and scoring validation folds with and without each cross-venue feature.

## Conclusion

The current evidence is best read as coincident venue state / slow regime and basis convergence, not true quote lead-lag.

For the next BONK orderbook pass, keep USDC/USDT basis, spread difference, activity share, and microprice disagreement in the feature set as venue-state controls. Do not promote them as true lead-lag direction factors unless a fresh window shows larger quote-lead asymmetry, stable fold signs, and incremental residual value after depth, RV, and common-mode controls.
