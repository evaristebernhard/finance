\section{最后的阅读建议}

不要一上来读完整 \code{runner/src/lib.rs}。先把下面这条链手算明白：

\begin{lstlisting}
decision_frame row
-> TFI trigger
-> membership_set
-> base_weight
-> R5/frames cell
-> gamma
-> target_exposure
-> admission
-> actual_exposure
-> fixed60 exit
\end{lstlisting}

这条链看懂以后，再回去读 Rust Runner，你会发现它只是把这条链放进一个更真实、更可审计的本地交易所。
