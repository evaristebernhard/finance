# CCUSDT Books And Reading Map

These books are explanatory layers. They do not replace the raw reports or the
system source code.

## Recommended Order

1. `ccusdt-factor-analysis/`: factor-analysis textbook. Use it when the question is about TFI, R5, depth, spread, release/decay, or runtime-safe factors.
2. `ccusdt-engineering-codebook/`: code-reading guide. Use it when the question is where the Python Bot, Rust Runner, fast runner, diagnostics, and artifacts live.
3. `ccusdt-data-structure-booklet/`: data-structure walkthrough. Use it when the question is how a market event becomes a monitor chain row.
4. `ccusdt-replay-exchange/`: broader replay-exchange research book. Use it as narrative context after the three focused books.
